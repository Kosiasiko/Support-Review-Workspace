# Support Review Workspace

A full-stack learning project for reviewing AI-drafted customer support replies with human oversight.

## Project Goal

The application allows customer-support agents to review AI-drafted replies either approve, reject before sending to client.

## Technologies

- HTML
- CSS
- JavaScript
- TypeScript
- Node.js
- REST APIs
- Git/GitHub
